Aluminum 隐私政策

生效日期：2026-07-28

本政策说明 Aluminum 浏览器扩展如何处理数据。“Aluminum”指本扩展及其开发者。

1. 摘要

Aluminum 不运营开发者后端、账号服务、分析服务或广告 SDK。这不代表没有数据离开你的设备。当你主动发起 AI 请求时，Aluminum 会把近期对话内容和与当前页面有关的工具结果，由扩展直接发送到你配置的 AI Provider 端点。接收并处理该请求的是相应 Provider，而不是 Aluminum；其处理受该 Provider 自身条款和隐私政策约束。

Provider 设置、API Key、同意状态、界面偏好和对话历史保存在你的本机浏览器中。Aluminum 不出售用户数据。

2. 我们处理的数据

数据类别 可能处理的内容 本地处理方式 对外传输

就 Chrome Web Store 披露而言，Aluminum 将 Website content 标记为收集/处理，因为与当前页面有关的内容会为了核心功能传输到用户自行选择的 AI Provider。Aluminum 开发者不会通过 Aluminum 后端接收这些内容。

3. 数据用途

Aluminum 仅为用户请求的核心功能处理数据：理解当前页面、回答基于页面的问题、分析页面实现方式，以及执行已获批准的页面操作。写工具运行前会展示确认；该决定会在当前一轮内沿用。

Aluminum 不会把数据用于广告、画像、信贷或资格判断、无关的产品开发，也不会向第三方出售数据。你配置的 AI Provider 可能有自己的处理、保留或模型训练条款，你需要另行查阅。

4. 首次使用同意

在产品界面可用前，侧边栏和设置页会显示隐私说明。在存在当前版本的有效同意记录之前，Aluminum 不会初始化 Agent 运行、提取页面内容、截取页面或调用 AI Provider。

选择“暂不继续”不会保存同意，隐私说明会继续显示。选择“同意并继续”会把带版本号的同意记录保存到 chrome.storage.local。如果读取或写入同意记录失败，Aluminum 会以关闭方式失败并保持产品不可用。未来如对数据使用作出实质性变更，将要求新的同意版本。

5. 本地存储与删除

  • Provider 设置、API Key、同意状态、语言和主题保存在 chrome.storage.local。
  • 对话消息保存在浏览器本地 IndexedDB。
  • 标签页与对话的对应状态及撤销快照暂存在 chrome.storage.session。
  • 页面工具结果和截图 data URL 不会写入 Aluminum 的持久化对话数据库。

你可以在 Aluminum 中删除单个对话并移除 Provider 配置。清除本扩展的浏览器数据或卸载 Aluminum 会删除其本地数据。删除 Aluminum 本地数据不会删除 AI Provider 已处理或保留的副本；这些副本需按相应 Provider 的控制方式和政策处理。

6. 第三方 AI Provider

AI Provider 端点由你选择和配置。Aluminum 支持 OpenAI 兼容和 Anthropic 兼容 API，包括自定义或本地部署的端点。

每次 AI 请求时，Aluminum 会直接连接到已配置的 Base URL，并可能发送模型标识、系统指令、工具定义、当前提示、近期对话上下文和与页面有关的工具结果。API Key 会作为该端点的认证凭据发送。Aluminum 不通过开发者运营的服务器代理这些请求，也无法控制 Provider 的安全、保留、训练或披露做法。

使用 Provider 前，请查阅其隐私政策和服务条款。不要提交你无权向该 Provider 分享的页面内容或对话内容。

所有远程 Provider 都应使用 HTTPS Base URL。Aluminum 会按配置原样请求该 URL，不会把不安全的远程 HTTP URL 自动升级为 HTTPS。在同一设备运行 Provider 时，可以使用 http://localhost 等回环 HTTP URL。

7. 浏览器权限

Aluminum 1.1.0 使用以下权限：

权限 用途
activeTab支持由用户调用的当前活动页面访问
tabs识别并校验目标标签页、读取其标题与 URL、打开扩展设置页，以及执行用户请求的导航
scripting在目标页面运行随扩展打包的读取与结构化写入函数，并捕获撤销状态

sidePanel承载 Aluminum 的主要界面
主机访问权限：<all_urls>让同一个当前页面 Agent 可在用户选择的 HTTP 和 HTTPS 网站上工作，并获取页面引用的资源

用户发起 Agent 请求后，只读页面工具可以运行。每轮第一次写操作执行前需要确认。Aluminum 不会在后台被动建立浏览历史画像。

8. 外部资源与 SSRF 防护

进行页面实现分析时，Aluminum 可能会跟随当前页面 <script src> 和样式表 <link href> 中的 HTTP 或 HTTPS 地址获取源文本。请求会直接发送到相应资源主机，该主机可能收到 IP 地址等正常网络元数据。

获取前，Aluminum 会拒绝非 HTTP(S) URL，以及字面匹配 localhost、未指定地址、回环地址、常见私有网段、链路本地地址、IPv6 唯一本地地址及这些地址的 IPv4 映射 IPv6 形式的主机。重定向请求使用手动模式：如果浏览器公开了重定向目标，Aluminum 会解析并验证该目标后再发出下一次请求；如果 Chrome 将目标隐藏为不透明重定向，Aluminum 会拒绝该重定向，而不会跟随无法验证的地址。允许获取的源文本可能作为本次分析的一部分发送到你配置的 AI Provider。这些检查会降低服务端请求伪造（SSRF）风险，但不能保证阻止所有网络或 DNS 类攻击；请只在你信任的页面和网络中使用 Aluminum。

9. 儿童隐私

Aluminum 不面向 13 岁以下儿童，也不会有意索取儿童个人信息。Aluminum 不运营账号或年龄验证服务。如果父母或监护人认为儿童输入了个人信息，应清除本扩展的本地数据，就已传输的副本联系所配置的 AI Provider，也可以通过下方地址联系我们。

10. Chrome Web Store Limited Use

Aluminum 对从 Google API 获得的信息的使用和传输，遵守 Chrome Web Store User Data Policy，包括其中的 Limited Use 要求。数据仅用于提供或改进面向用户的核心功能；传输仅限于用户选择的 AI Provider，以及为完成用户请求而必须联系的资源主机。

Aluminum 不出售用户数据，不将其用于广告，不将其用于判断信用或贷款资格，也不会通过 Aluminum 后端让人工读取这些数据。

11. 政策变更

如本政策发生变化，我们会更新生效日期并在项目仓库中记录变更。如果变化实质性影响 Aluminum 处理的数据或数据发送位置，Aluminum 会提升同意版本，并在产品界面再次可用前重新请求同意。
